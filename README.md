# R6T5 单词收藏夹（浏览器 MV3 扩展）

在必应词典、有道词典页面一键收藏单词（英文 / 音标 / 词性 / 中文释义），在弹窗里二次编辑，指定目标词书与课时，通过单词闯关站点的桥接页合并进你的自定义词书，并由站内现有 D1 同步推送到云端。

## 功能
- 词典页右下角「⭐ 收藏到词书」按钮；识别不到单词时支持先划词再收藏。
- 自动抓取：主词条、音标、全部词性与释义；抓不到的字段在弹窗手动补全。
- 弹窗队列：逐条编辑英文/音标/词性/释义、删除、清空。
- 指定「词书名称 + 课时名称」，一键在桥接页合并（按名称匹配已有词书/课时，没有则自动新建，按英文去重）。

## 本地安装（开发者模式）
1. Chrome / Edge 打开 `chrome://extensions`（Edge 为 `edge://extensions`）。
2. 右上角打开「开发者模式 / Developer mode」。
3. 「加载已解压的扩展程序」，选择本文件夹。
4. 打开必应/有道词典查词页，点右下角按钮收藏。

## 使用流程
1. 在词典页查词 → 点「⭐ 收藏到词书」。
2. 点扩展图标打开弹窗，核对/补全音标、词性、释义。
3. 填「归入词书名称」「课时名称」（默认 我的收藏 / LV1）。
4. 点「同步到游戏词书 →」，自动打开站点桥接页，提示新增/跳过数量后即可关闭。

## 目录结构
```
├── manifest.json          # MV3 清单，最小权限（仅 storage）
├── src/
│   ├── extract.js        # 页面抓取纯函数（多选择器+正则+划词兜底）
│   ├── content.js          # 注入收藏按钮、入队 chrome.storage.local
│   ├── popup.html / .css / .js  # 队列编辑、选词书课时、打开桥接页
├── icons/                 # 16/48/128 图标（提审前替换为正式 png）
├── PRIVACY.md             # 商店隐私政策
└── README.md
```

## 词书数据格式（与游戏站一致）
`localStorage.wordGameCustomBooks`：
```json
[{ "id": 1700000000000, "name": "我的收藏",
   "data": [{ "name": "LV1", "words": [
     { "en": "apple", "phonetic": "/ˈæpl/", "pos": "n.", "cn": "苹果" }
   ]}] }]
```

## 桥接页
- 游戏仓文件：`dict/bridge.html`（部署到 `https://wordgm.r6t5.dpdns.org/dict/bridge.html`）。
- 协议：扩展把 `{bookName, levelName, words}` base64url 编码进 URL `#data=`，桥接页解码、合并、写回 localStorage 并 POST 到现有 `/api/kv`。

## 上架（Chrome Web Store / Edge Add-ons）准备清单
- [ ] 替换 `icons/` 正式图标（128×128 主图 + 商店展示图 1280×800 / 640×400）。
- [ ] 隐私政策 URL（托管 PRIVACY.md 内容，商店必填）。
- [ ] 商店描述：一句话简介 + 详细说明 + 截图（收藏按钮、弹窗队列、同步结果）。
- [ ] 权限用途声明：`storage`=本机暂存收藏队列；内容脚本仅限两个词典域名读取当前词条。
- [ ] 无 host_permissions、无后台常驻、无第三方请求，便于过审。

## 已知限制 / 待实测微调
- 词典页为 JS 渲染且会改版，静态抓取拿不到 class；当前用多候选选择器 + 音标/词性正则 + 划词兜底。本地加载后按真实页面在 `extract.js` 增补选择器即可。
- 仅支持必应、有道；后续按同样模式在 manifest `matches` 与 `extract.js` 增加新站点。
